# 需求文档

## 产品定位

UUUtil 是一个个人辅助桌面工具，采用悬浮球 + 面板的交互形式，把日常高频的小工具集中在一个可快速呼出的本地应用中。

核心目标：

- 低打扰：常驻悬浮球，不占用 Dock/任务栏主要空间。
- 快速呼出：支持点击悬浮球、托盘菜单和全局快捷键打开/关闭面板。
- 本地优先：知识库、白板等个人数据存储在本机 SQLite/sql.js 数据库中。
- 可扩展：功能按插件/页面拆分，核心只提供窗口、事件总线、数据库、AI 调用等基础能力。

## 当前核心需求

### 1. 悬浮球与面板

- 桌面常驻悬浮球。
- 点击悬浮球可展开或收起主面板。
- 右键悬浮球显示菜单：展开/关闭面板、开发者工具、退出。
- 系统托盘支持展开/关闭面板和退出。
- 面板右侧提供快捷入口：AI 配置、开发者工具、关闭面板。
- 支持全局快捷键切换面板：
  - 主快捷键：`Control + Shift + U`
  - 备用快捷键：`Option + Space`

### 2. 面板导航与动效

- 面板顶部为功能导航栏。
- 导航内容区使用横向滑入/滑出切换动画。
- 多卡片页面切换时，卡片应按顺序错峰进入/退出，增强空间切换感。
- 右侧工具按钮合并在一个半透明按钮组内，避免分散视觉焦点。

### 3. 首页多功能白板

首页定位为临时记录和资料收集画布。

#### 画布

- 白板应充满首页主要空间。
- 左侧提供竖向工具栏。
- 支持多个画布：新增、切换、删除。
- 画布可命名，标题宽度随内容自适应。
- 画布数据持久化到本地数据库，重启或切换画布不丢失。

#### 便签

- 支持新增便签。
- 便签支持拖动和缩放。
- 便签标题可编辑。
- 便签正文可编辑。
- 便签可切换底色。
- 便签正文复用底部统一文字工具栏。
- 便签头部操作使用图标按钮，不使用文字按钮。

#### 文本框

- 文本框行为参考 PPT/draw.io：
  - 默认状态不进入编辑模式。
  - 单击选中文本框。
  - 选中态可直接拖拽框体移动。
  - 双击进入编辑模式。
  - 点击画布空白处退出选中和编辑焦点。
- 选中文本框且非编辑状态时：
  - `Delete` 删除文本框。
  - `Backspace` 删除文本框。
- 支持 `Command/Ctrl + Z` 回滚白板操作。
- 支持键盘直接输入：在鼠标位置创建文本框。
- 支持外部文本粘贴：在鼠标位置创建文本框。
- 粘贴文本时，根据内容自动计算初始宽高。
- 支持底部统一文字工具栏：加粗、下划线、删除线、字号调整、五色文字颜色。

#### 图片和附件

- 支持从剪贴板粘贴图片/文件。
- 支持通过工具栏导入文件。
- 图片以画布元素展示。
- 附件以文件卡片展示，并可下载。

#### 右键菜单

- 画布空白处右键：添加便签、添加文本框、粘贴文本、导入文件、清空当前画布。
- 元素右键：删除。

### 4. 计算器

- 支持鼠标点击输入。
- 支持键盘输入数字、运算符、括号、小数点等。
- `Enter` 或 `=` 执行计算。
- `Backspace` 删除输入。
- `Escape` / `Delete` 清空。
- 计算结果应作为下一次计算的起点。
- 计算历史在显示区域内向上滚动，最多保留 10 条。

### 5. 开发工具

- JSON 格式化/压缩。
- SQL 美化/压缩。
- Base64 编解码。
- 时间戳转换。
- 当前时间多格式展示：毫秒时间戳、秒时间戳、ISO、UTC、本地时间、日期、时间。
- 正则测试。
- UUID 生成。
- 插件 action 不存在时应返回明确错误信息，避免按钮无响应。

### 6. 知识库

- 支持笔记列表、创建、编辑、删除。
- 支持分类、标签、搜索。
- 数据持久化到本地 SQLite/sql.js。
- 空状态使用统一图标风格。

### 7. AI 配置与调用框架

- 支持配置多个 OpenAI-compatible Provider。
- 支持默认 Provider、默认模型和运行参数。
- 渲染进程通过 `window.assistant.ai` 调用 AI 能力。
- 翻译等页面复用统一 AI Chat 入口。

### 8. 焦点管理

焦点管理定位为“注意力观察系统”，不作为 TODO、项目管理或手动打卡工具使用。

- 焦点由助手、MCP、Skill 或其他外部系统自动创建和检视，界面不提供人工 check-in 表单。
- 焦点对象记录名称、描述、关注模式、期望退出条件、标签、权重、创建时间、更新时间和最近衰减时间。
- 检视记录记录时间、能量状态、阻塞、下一步和备注，用于还原一次对话或工具调用产生的注意力信号。
- 允许通过受控接口修正名称、描述、标签、关注模式和期望退出条件。
- 权重应由系统根据时间衰减和重复检视自动维护，用户不需要手动维护数值。
- 健康度和告警由系统计算，用于提示持续关注、漂移和长期未检视的主题。
- 期望退出条件在当前版本只展示，不驱动自动归档或完成状态。
- 标签以 JSON 形式保存，便于 MCP 和外部系统传入结构化分类。
- 焦点界面以只读看板为主：泡泡图展示关注分布，列表和详情展示元数据、检视历史和告警。
- 泡泡图按小时级对数时间圈表达最近关注，近期焦点靠近中心，泡泡大小表达权重，悬停展示内容。

### 9. MCP 与外部接入

- 应用启动后提供本机 Streamable HTTP MCP 服务，默认地址为 `http://127.0.0.1:17878/mcp`。
- 外部系统应优先调用应用内 HTTP MCP 服务，不应各自启动独立进程直接写同一个 sql.js 数据库。
- MCP 工具调用需要串行化，避免同时写入造成数据库覆盖或状态丢失。
- MCP 调用应进入统一日志系统，记录工具名、调用来源、耗时、成功/失败和错误摘要。
- stdio MCP 入口保留为兼容层，默认代理到应用内 HTTP MCP 服务；只有显式开发场景才允许 direct-db 模式。
- 开发期允许使用脚本清空焦点数据，但不暴露正式 `focus_reset_all` MCP 工具。
- Codex/其他 Agent 可通过 `uuutil-focus` Skill 在每个实质性回合末尾执行 `focus_list`、必要时 `focus_create`，然后 `focus_check_in`。

## 非功能需求

- 主进程与渲染进程职责清晰，IPC 接口通过 preload 暴露。
- 插件之间不直接 import，跨模块通信通过 EventBus。
- 数据写入后必须持久化。
- UI 图标优先使用 Lucide，缺失时再考虑 Tabler Icons。
- 面板交互应尽量避免误选中文本、误拖动、焦点残留等桌面应用常见问题。
- 日志、MCP、IPC 和插件写入都应避免记录敏感正文、Token、完整请求头和大体积附件内容。
- 多入口写数据库时应优先由应用主进程持有连接，外部系统通过 MCP/IPC 接入。
