# 001 - 项目脚手架搭建

## 为什么做
构建插件化架构的最小可运行骨架，验证核心机制（插件加载、事件通信、数据库）

## 做了什么
- Electron 主进程 + React 渲染进程
- core 层：EventBus、SQLite数据库、插件加载器
- hello-world 示例插件
- 防御性架构规则（插件隔离、事件通信）

## 关键决策
- Electron + React + TypeScript + better-sqlite3
- 插件间通信：event-bus（不引入微服务框架）
- 数据库：SQLite（本地文件，零运维）
- 不使用微前端、不使用微服务、不使用任何框架（保持控制权）

## 插件边界
每个插件 = 独立目录，暴露 api.ts

## 不做的事
- 不实现任何实际功能（这是骨架）
- 不配置 CI/CD
- 不写测试（单体项目，功能稳定后再补）
