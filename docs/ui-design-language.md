# UUUtil 界面设计语言

> 源自 2026-09 事项管理插件（驾驶舱版）的设计实践（Multica HANJ-75/HANJ-77，v7 定稿原型）。
> 本文档两部分：**设计思路**（为什么这样设计）和**风格规范**（直接可抄的 token 与组件词汇）。
> 其他部分开发参照时：**学思路 > 抄皮肤**——浅色 tab 参照的是方法论，不是把驾驶舱皮肤糊上去。

---

## 一、设计思路（方法论）

### 1. 场景先行，拒绝品类惯性

面板是**瞬态**的：双击球呼出、用完即走。它不是全屏应用，UI 必须服务于"秒级进出"的场景，而不是把 Todoist/Things 的三栏布局抄进来。先写下真实使用场景，再让每个元素向场景自证必要性：

- 快速捕捉（最高频，必须零摩擦）
- 今日一瞥（是"扫"，不是"管理"）
- 随手勾掉（要有正反馈）
- 外部写入的展示面（CLI/skill 写入，面板是查看窗口）

反例：三栏 todo 布局（视图侧栏 + 列表 + 详情栏）是为长期驻留窗口设计的品类惯性，塞进瞬态面板就是挤、满、累。**每加一个区域，先问"哪个场景需要它"。**

### 2. 单栏聚焦流

操作区永远只有一个——中央列表。视图切换退化为标题旁 chip，详情编辑退化为行内手风琴，不分裂视线。单栏的另一个好处：面板拉窄布局依然成立。

### 3. 侧栏纪律：只允许被动遥测

侧栏不是不能放东西，是只能放**只读仪表**：不抢操作、数据从现有模型免费算出（计数/聚合/筛选）、不需要新的交互设计。清单能量条、近 7 日产出、月历、今日时间轴都是遥测；视图导航和详情编辑不是。拿不准就问：它被动吗？数据免费吗？

### 4. 一个世界一套语言

每个 tab 可以有自己的视觉世界（驾驶舱是暗色舱室，其余 tab 是浅色世界），但**世界内部必须完整自洽**：色彩、字体、组件、动效、文案腔调全部对齐。不允许一半浅色一半暗色、一半圆润一半硬朗的缝合怪。进入一个独立世界的 tab 应该有"走进另一个舱室"的仪式感。

### 5. 叙事对齐，不是贴皮

驾驶舱不是把界面画成飞船玩具，而是语义全对齐：事项=航行任务、今天=今日航段、逾期=红色警报、CLI 写入=UPLINK 上行链路。换皮不换骨的前提是骨（UX 骨架）已经被场景验证过。

### 6. 一个编排时刻

动效只传达状态（150–250ms），整个界面只留一个"编排时刻"作为正反馈点：勾掉完成的 200ms 绿色充能。其他地方不允许有编排动画。用户在工作流里，不要让他看表演。

### 7. 工艺底线（不可妥协清单）

- **图标必须来自真实图标库（本项目 lucide）或手绘 SVG，统一 24 网格、2px 描边、圆角端点。emoji 永远不做 UI 图标**；SVG sprite 用 `<symbol viewBox>` 不用 `<g>`（不携带视口信息会裁切）
- 文字对比度：正文 ≥4.5:1，氛围不能牺牲可读性
- 阴影必须有偏移+柔化（零偏移彩色光晕是装饰）
- 数字用 `tabular-nums`；计时/读数类用单宽字体
- 浏览器原生表面也是设计面：文本选中色、滚动条、focus 环、插入符色——默认样式不属于任何设计系统

## 二、风格规范（驾驶舱世界 token）

### 色彩（全部语义化，零装饰用色）

```css
--bg:        #060d18;  /* 深空底 */
--line:      rgba(103, 232, 249, 0.14);  /* 发丝线 */
--line-strong: rgba(103, 232, 249, 0.35);
--phos:      #67e8f9;  /* 磷光青：主色，选中/交互/主读数 */
--phos-dim:  #3b7d8c;
--amber:     #fbbf24;  /* 今日到期 / 中优先级 / 将到事件 */
--red:       #f87171;  /* 逾期 / 高优先级 / 警报 */
--green:     #34d399;  /* 完成 / 系统正常 */
--ink:       #d7ecf5;  /* 正文 */
--ink-2:     #8fb3c7;  /* 次级 */
--ink-3:     #5f8098;  /* 标签/弱化 */
```

规则：颜色只承担语义（状态、选中、优先级），不做装饰；发光（box-shadow glow）只跟随语义色用在交互态/状态点上，不大面积铺。

### 字体

```css
font-family: ui-monospace, "SF Mono", "JetBrains Mono", Menlo, "PingFang SC", monospace;
font-variant-numeric: tabular-nums;
```

单宽是仪表读数的语言；CJK 自动回落苹方。标签用 10–11px + `letter-spacing: 0.15–0.28em` + 英文大写（如 `TODAY // 今日航段`，双语标签是这个世界的一部分）。正文 13px，标题 15px 700。

### 质感元素

- **发丝线**：`1px solid var(--line)` 分隔行，不用卡片（卡片是懒惰的容器）
- **HUD 角括号**：录入台/选中面板的两角 10px L 形描边（`border: 1.5px solid var(--phos)` 裁两角）——这个世界的签名元素，一处到两处即可，不滥用
- **状态灯**：6px 圆点 + 同色 glow（PWR/NAV/COM）
- **背景**：径向渐变深空底 + 极弱扫描线（`rgba(255,255,255,0.016)` 1px/3px）+ 边缘网格（mask 弱化）——强度以"注意不到"为准
- **圆角**：小圆角语言（3–4px 硬朗）；呼吸光标 `steps(1)` 闪烁

### 组件词汇

| 组件 | 形式 |
|---|---|
| 勾选圈 | 圆形描边，边框色=优先级（红高/橙中/青低），完成=绿底+对勾+glow |
| chip | 3px 圆角描边小胶囊，选中=语义色描边+淡底+微 glow |
| 能量条 | 3px 高，清单色+glow，按最大值归一 |
| 段条 | 分段充能格，完成段=绿 glow |
| 行 | 发丝线分隔，hover 极淡青底（`rgba(103,232,249,0.04)`），选中行角括号 HUD 框 |
| 分组标签 | 10px 大写字距 0.28em + 尾部延长横线（`::after flex:1 1px`） |
| 底部状态栏 | 10px 字距 0.1em，能力提示（快捷键/CLI/同步目标） |

### 动效

- 时长 150–250ms；缓出用指数缓出（`cubic-bezier(0.34, 1.56, 0.64, 1)` 仅用于弹入）
- tab 进入：200ms 开机微闪，仅一次不循环
- 事件反馈：外部写入 → COM 灯闪两下 + 行滑入高亮
- 列表滚动：底部 `mask-image` 渐隐代替生硬截断

## 三、其他部分参照指南

**浅色 tab（知识库、剪贴板等）：参照思路，不参照皮肤。**

1. 先写该 tab 的三个以内真实场景，删掉不为场景服务的区域
2. 操作区收敛到一个；其余信息只做只读呈现
3. 检查工艺底线清单（图标/对比度/阴影/数字/原生表面）
4. 全界面最多一个编排时刻

**想开新的暗色独立世界 tab：可以，但整个世界一起设计**（色彩/字体/组件/动效/文案腔调一次定齐），不允许暗色皮+浅色组件缝合。

**反 AI 味禁令（任何世界通用）**：emoji 图标、渐变文字、卡片套卡片、标题上的 kicker/eyebrow 小标签、无信息量的 01/02/03 编号、装饰性玻璃拟态、为大数字而大数字的 hero 指标。
