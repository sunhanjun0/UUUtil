## 二、需求优先级排序（MoSCoW）

### 🔴 P0：必须立即修复（阻塞性 bug）

| 优先级 | 需求 | 类型 | 理由 |
|--------|------|------|------|
| **P0** | 修复 reminder Agent waiter bug（BUG-1） | Bug修复 | 影响功能正确性，`uuutil-reminder` skill 核心价值（阻塞式 wait）完全失效 |

## 三、核心用户故事

### 3.1 剪贴板历史（P1）

```
作为 用户，
我需要 系统自动记录我复制过的文本和图片，
以便 我能随时找回之前复制的内容，不用来回切换窗口重新复制。
```

```
作为 用户，
我需要 在剪贴板历史中搜索、收藏和删除条目，
以便 快速定位重要内容，清理敏感信息。
```

```
作为 用户，
我需要 剪贴板历史数据完全存储在本地，
以便 敏感信息不会泄露到云端。
```

### 3.2 知识库改造（P2 核心重构）

```
作为 用户，
我需要 打开知识库就能看到笔记列表和预览，
以便 快速扫视多个笔记找到我要的那个。
```

```
作为 用户，
我需要 给重要笔记打星标，
以便 快速找到和优先展示重要内容。
```

```
作为 用户，
我需要 基于全文搜索（FTS5）的搜索，支持分词和权重，
以便 快速搜到我要找的内容。
```

```
作为 用户，
我需要 左侧编辑 Markdown、右侧实时预览的双栏模式，
以便 在窄面板下也能有足够的编辑和预览空间。
```

### 3.3 定时提醒（P2）

```
作为 用户，
我需要 设置定时提醒（一次性和重复性），
以便 在规定时间收到通知，不会忘记重要事项。
```

```
作为 用户，
我需要 提醒到达时通过系统通知和悬浮球提醒我，
以便 即使 UUUtil 在后台也能收到提醒。
```

### 3.4 知识库 RAG（P2）

```
作为 用户，
我需要 在 AI 助手中引用知识库中的笔记内容，
以便 基于我积累的知识进行问答和总结。
```

### 3.5 批量文件处理（P2）

```
作为 用户，
我需要 批量处理图片（压缩、格式转换、调整大小），
以便 快速准备发布用的素材。
```

```
作为 用户，
我需要 批量重命名文件，
以便 整理下载的文件和截图。
```

## 五、风险与依赖

| 风险 | 影响 | 缓解措施 |

| 无自动化测试 | 回归风险高，尤其 reminder 复杂逻辑 | P0 bug 修复后至少为 reminder 核心逻辑加最小测试 |

## 六、总结

UUUtil 当前已是一个**功能完整、架构稳定**的个人辅助工具。内核基础设施成熟，6 个功能插件均可正常使用（除 reminder Agent waiter bug 外）。

**核心结论**：
1. **首要任务**：修复 reminder Agent waiter bug（P0）——这是当前唯一影响功能正确性的严重 bug
2. **最高价值新功能**：剪贴板历史（P1）——投入产出比最高的新功能
3. **最大改造项**：知识库重构（P2）——从"编辑优先"改为"浏览优先"，提升核心体验
4. **补全项**：定时提醒 + 知识库 RAG + 批量文件处理（P2）——完善插件生态

建议按 阶段 0 → 阶段 1 → 阶段 2 → 阶段 3 的顺序推进，每个阶段有明确的交付物和验证标准。
